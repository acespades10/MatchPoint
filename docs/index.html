A FEW GOOD QUESTIONS

Before your next step.

Is this the actual matching application?

This page is an interactive project guide hosted on GitHub Pages. The actual app runs on Node.js and Express. Clone the repository, run npm ci and npm start, then open http://localhost:3000. The local app has a no-key sample-profile mode.

What happens to a real résumé?

In the actual app, PDF text is extracted on the server and sent to your configured AI provider to create a profile. Sessions are held in memory. Saving an AI connection in the current app stores its URL and key in browser local storage. This guide collects neither résumés nor credentials.

Does a high score guarantee an internship?

No. Scores are heuristic estimates of fit, not hiring probabilities or employer decisions. Company-side signals use learnability and recorded active-intern status. Confirm current openings, requirements, and terms with the company and institution.

Why might a higher score appear lower down?

The actual app prioritizes direct industry matches, then adjacent ones. Within each tier, partners with active interns come first, followed by bilateral score. A score alone doesn’t determine the final order.

Do preference changes search all companies again?

No. Re-ranking uses the relevant pool from the initial run. Changing preferences does not restore companies that were eliminated during initial screening. Start a new run to reconsider the full dataset.
